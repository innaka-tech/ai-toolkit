## Harden aitk run's trust boundary

aitk run's trust boundary hardened over nine security review rounds: a per-task guard restores aitk.toml, other tasks, the agent's own task identity and protected fields (reviews, UAT, audit, regression, profile, criteria, workers, created_by, base, created, branch, legacy), git config and its includes (effective config + branch compared, fail closed), symlink/hard-link aware; new tasks arrive as plain work; commits skip hooks, rebuild the index from HEAD, refuse sequencer state and verify every staged blob of aitk's state against the file aitk verified; anything unrestorable stops the run in every mode. Limits documented: not a sandbox.
